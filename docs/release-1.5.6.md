# LaTeX Islands 1.5.6

- Automatically load Circuitikz for common circuit components inside `tikzpicture`, including ground nodes, resistors, capacitors, diodes and sinusoidal voltage sources.
- Preserve explicit package options, custom TikZ styles and native TikZ circuit libraries. Labels and comments do not trigger this component detection.

Includes the PDF dark-theme contrast fix in [1.5.5](release-1.5.5.md).

For an unpacked installation, reload the extension and refresh ChatGPT. Previously failed circuit fragments can then render without editing their source.
